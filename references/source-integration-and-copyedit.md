# 外部教材融合与图文校对

用户给了教材、截图、论文或课程材料，要写进一部已有的“轻松学”小书时，先读现有小书的目录和相关章节，再读外部材料。目标是补足读者最容易卡住的步骤，让读者能照着练、知道怎样检查；不要按教材页码重排小书。

## 一、先拆材料，再决定写到哪里

阅读所给内容，记下五类信息：**讲了什么事实或动作、动作的先后与方向、适用条件、常见错误与改法、可供初学者练习的办法**。图还要单独记下它想说明什么。记录每项的出处页码、链接或截图文件；只看到节选时，不推断缺失页面的结论。

再把每项对到现有书稿：它解决读者的哪一个难处？原书哪一章已有铺垫？需要补正文、例子、练习、答案，还是只须改一个误导人的句子？优先补读者马上能做的步骤。一次修订同时检查目录、术语、章间引用和附录，避免正文加了练习，答案却仍讲旧做法。

材料提供事实、动作和教学线索；用本书的语言重新解释，不逐段改写成同义句，也不沿用材料的段落次序。区分来源的结论、本书的简化和自己设计的练习；注明可核查的出处，自编练法如实标明。拿不准的技术断言先核查，不靠一个比喻或一次练习结果作必然推断。

## 二、把关键知识变成练习路线

“轻松学”的关键常在读者能亲手试的过渡练习。先找关键技能能在哪种简化情境里练清楚，再逐步加入真实任务的复杂处。蛙泳可以从椅上辨认动作次序，到池边试水、浅水扶壁练单项，最后在有人看护的浅水区练完整配合；别把这些场景机械套到别的主题。

每一步按主题交代：

1. **起点**：读者需先会什么；环境、器材或输入材料有什么要求。
2. **操作**：做什么，按什么顺序；涉及身体或工具时，写清位置与方向。
3. **检验**：练完能观察、算出或核对什么；自己看不到的动作，由谁从哪里观察。
4. **修正**：常见错误出现时，先改哪一处；做不稳就退回哪一步。
5. **结束**：何时可以进入下一步，何时应停下。运动、实验或设备操作还须写明看护与安全退出条件。

练习要能检验本步教的事。扶住池壁可以观察两脚是否同时推水，却不能用“身体没有前进”判定蹬腿无效；离开池壁后，滑行也只是一条线索，仍会受起步和身体姿势影响。这种限制要写在练习旁边，别把结果说成保证。

## 三、图只补文字讲不清的地方

动作方向、时序或空间位置难以靠几句话辨认时，可以画教学图。先确定图要回答的一个问题，再根据本书的练习路线绘制；不要因为材料里有图，就把原图直接放进书里。确需沿用原图时，先核查许可或取得授权，并标明出处。

图里的姿势、箭头、编号与正文必须说同一件事。校对范围包括画面上的字、图注、Markdown 替代文字，以及 SVG 的 `title`、`desc`。渲染后实际看一遍，检查文字是否被裁切、箭头是否指错、编号是否与正文错位。纯文字版须能独立教会读者；移除图片后，动作的方向、顺序和退出条件仍应写得明白。若用户指定纯文字版，不因网页用了图就给纯文字稿添图。

## 四、做两轮不同的校对

**先查内容。** 逐章核对事实、来源、练习顺序、观察办法、答案与安全条件；再横向核对相邻章节和图文。尤其留意前一幅图说“开始收腿”，后一幅图却说收腿已开始，或正文提到图上根本没有的椅子练习。区分“可能提示某个问题”和“证明原因就是它”。

**再查中文。** 把每句当成第一次读这本书的人会看到的句子，大声读一遍：主语是谁，动词搭配什么，动作朝哪里去，读者能否真看见或感觉到，省掉的词会不会迫使读者猜。不要为了短而造口令。比如：

| 含混的写法 | 写清楚以后 |
|---|---|
| “听听有没有前滑” | “蹬腿并拢后，保持双腿伸直，留意身体是否还能向前滑行。” |
| “能站稳的短段” | “只在双脚能踩到底的浅水区游一小段。” |

脚本可以检查文件名、禁词和章节体例，查不出这些病句。跨多章或有多幅图时，请另一位审读者独立通读，专找不清楚的搭配、缺席的观察者、图文矛盾和说得过于肯定的结论。改完重读受影响的整段，别只替换一个词。

## 五、按交付形式验收

有 Markdown 书稿、纯文字下载、网页等多个版本时，明确哪份是修订源，逐章同步其余版本。检查图文版新增的说明在纯文字版是否仍说得通；下载文件也须重新生成并抽查。用户要求发布时，分别核对源文件、构建结果、部署状态和公开页面；本地预览或推送成功，都不能单独证明读者已经看到新版。
